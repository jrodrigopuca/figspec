# figma-work

Salidas de trabajo del extractor (`FIGMA_OUT_DIR=figma-work`): una subcarpeta por componente con `component.json`, los CSS Modules, los assets, el visualizador (`viewer.html`) y, con `FIGMA_REACT=true`, los componentes React.

Se regeneran en cada `npm start` / `npm run extract`: no edites estos archivos a mano.

Su contenido no se versiona.
